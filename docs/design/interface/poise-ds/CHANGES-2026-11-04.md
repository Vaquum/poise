## What was wrong in the mocks

Reading the merged contract also showed five mistakes of the mocks' own, all fixed:

- **The held task.** #502 was held because a check failed in the merge queue. On `main`, a failed check or a conflict there goes to a fresh repair; only a removal by hand, or an unknown one, holds for a decision. It now reads *Someone removed #502 from the merge queue by hand*, on Observe and Overview alike.
- **Overwriting a change.** The conflict offered *Save mine over it*, which `main` has no way to do. It is gone.
- **Load theirs did nothing.** The latest text never replaced the draft. It does now.
- **A lost draft.** Editing a second issue discarded the draft of the first. It is now refused, and the draft stays.
- **Explain.** On a chat's row it showed nothing while waiting and asked again on each press. It now does what `main` does: one question, *Asking the Switchboard…* with its dots, the answer in three parts with when it was given, *Hide explanation*, and on failure the reason with Try again (`?explain=fail`). It is unavailable while the Switchboard is not running, unless already asked.

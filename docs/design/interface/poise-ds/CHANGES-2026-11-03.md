# What changed in Poise, 28 October to 3 November, and how the designs follow

`main` has moved since, with v2 published: [CHANGES-2026-11-04.md](CHANGES-2026-11-04.md) says what followed.

Read on 3 November from `main` at `e7b8fea` (1 November). The baseline is `77976fd`, the commit the 28 October audit read. Since then 48 pull requests have merged into `main`. One more merged into a feature branch, and four are open, among them the owner's UX draft, #790.

Each one was read: its description, its changed files, and, where it touches the interface, the code and the docs. Twelve change what a person sees. The rest are behavior-chain, resource, review and ledger work, with no design impact beyond the states and reasons they now report.

The mocks were last changed on 23 October. So this round also builds what the [28 October audit](CHANGES-2026-10-28.md) found and the [chain proposal](CHAINS.md), neither of which had reached the mocks yet.

### Everywhere

- **Failures say what they depend on** (`docs/Error-State-Contract.md`, #758).
  - A failure that depends on its input is Needs you, with the action named.
  - One that depends on something else, such as a provider, a quota or capacity, is Waiting on that thing.
  - An effect that cannot be proven is Blocked, *Not confirmed*, until it is reconciled.
  - The registry's words follow this.
- **Motion** (Natural-Flow.md, #790). The only repeating animation is the working pulse, and only while work is actually in flight. A transition the browser skips is not an error, and nothing logs one.
- **Routes back** on every place. `?back=` names the place you came from, and links carry it: Board, Observe, Overview, Editor, Settings, Chat and the Manager.
- **One world.** A task, a chat, a pull request or a slot says the same thing wherever it shows: the PR review on #492 that Tasks names is a run in Behaviors; the Settings rows for the chain's behaviors link to their tasks; a new issue is #510, and a new worker takes the next number after W7.
- **The element review** has 454 rows, covering 302 live behaviours, and every row opens its element in place, revealing what only shows on use: an edit, a composer, a step of setup, a server's details, reasoning, a queue, a selection's actions, a held update.

## 3. Decisions

Built on the recommended option, and easy to change:

1. **The task as the unit of work.** One card per task on Board, Observe → Tasks, holds in Answer here, and the work table's rows (CHAINS.md, decisions 1, 2 and 4).
2. **A stalled worker is Blocked**, with what it left.
3. **Manual cards land at the top too.** #790, merged on 4 November, composes at the top but still appends a manual card at the bottom, out of view, under a test that names it. The mock puts it under the composer.
4. **What holds a Manager slot: main's rule.** Each worker chat holds one until it is closed, idle ones included, as your #675 counts them and #782 ships. It replaces the rule accepted on 22 October, an active worker turn, so the Manager, the idle-slot notice and Board can never disagree. Rhythm counts tasks in flight; Running at once still caps turns running together. Only you close a worker chat, and the Manager fills a free slot on its next turn, both as on `main`.
5. **The Manager's controls in main's words.** Stability is how the Manager takes a Poise release; Autonomy is what it decides and brings. The control shows exactly the words each Manager turn carries.
6. **Dark only.** The new interface is dark, as you asked for Poise "for now" and use it all day. The classic interface keeps Light and Dark until it is removed. Settings → General → Interface chooses between them per browser, and setup no longer asks for a theme. A light token set can be added through the three token layers if you want one later.
7. **The bell opens Overview.** It counts what Overview's level shows and opens Answer here, with a route back, so answering lives in one place, the command center you asked for. PRD #556's panel was the other choice.
8. **Behaviors keeps its name**, as you named it on 23 October. Tasks sits beside it; CHAINS.md's *Runs* is not taken.

None is left open. Each is easy to change, and the notes say what to change.
